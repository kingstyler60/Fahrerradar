## Waze aktivieren (optional, ca. 5 Minuten, kostenlos)

Die Website funktioniert auch ohne Waze. Mit aktivem Waze siehst du zusätzlich
aktuelle Community-Meldungen (Blitzer/Polizei, Unfälle, Stau, Sperrungen).

1. **Key holen:** auf `app.openwebninja.com` kostenlos registrieren →
   API „Waze“ abonnieren (Free-Tier, keine Kreditkarte) → API-Key kopieren.
2. **Key eintragen:** auf vercel.com dein Projekt öffnen →
   **Settings → Environment Variables** → neue Variable:
   - Name: `WAZE_API_KEY`
   - Value: dein API-Key (nur in Vercel eintragen, **niemals auf GitHub hochladen**)
   - Environment: Production, Preview, Development (alle Haken)
3. **Neu deployen:** Tab „Deployments“ → beim letzten Deploy die drei Punkte →
   **Redeploy** (Haken bei „Use existing Build Cache“ kann bleiben).
4. Fertig – auf der Startseite erscheinen Waze-Meldungen mit grüner Quellen-Markierung.

**Reicht das kostenlose Kontingent? Ja.** Der Free-Plan hat **50 Abfragen pro Monat**.
FahrerRadar holt die Waze-Daten deshalb nur alle **3 Stunden** neu und stoppt automatisch
bei ~44 Abfragen im Monat – dadurch bleiben immer 6 Abfragen Reserve und das Kontingent
hält den ganzen Monat. Im Quellen-Panel unten siehst du jederzeit, wie viele Abfragen
noch übrig sind („noch ~43 Abfragen diesen Monat“). Ist das Kontingent verbraucht,
pausiert Waze bis zum Monatswechsel – Radio-Feeds und Autobahn laufen unverändert weiter.
Die Waze-Meldungen können dadurch bis zu 3 Stunden alt sein; frische Blitzer-Meldungen
kommen zusätzlich live von Gong FM, Charivari, Ramasuri und Regensburg Digital.

## Fall A: Du hast schon V2/V3 online → Update einspielen

**Schnellweg (Dateien ersetzen):**
1. Entpacke das neue Zip (`fahrerradar`-Ordner).
2. Öffne dein Repo auf github.com → **„Add file“ → „Upload files“**.
3. Ziehe den **kompletten Inhalt** des Ordners hinein (Strg+A / Cmd+A → reinziehen). Die geänderten
   Dateien werden einfach überschrieben, der Rest bleibt gleich.
4. „Commit changes“ klicken → Vercel baut automatisch neu (1–2 Minuten). Fertig.
5. Wenn du Waze willst: einmalig den Schritt oben „Waze aktivieren“ machen.

## Fall B: Erste Veröffentlichung (Schritt für Schritt)

### 1. Zip entpacken
Du bekommst einen Ordner **`fahrerradar`**.

### 2. Repository auf GitHub anlegen
1. **github.com** → oben rechts **„+“ → „New repository“**.
2. Name: `fahrerradar` · Sichtbarkeit: **Public** (wichtig für den kostenlosen Vercel-Tarif).
3. Keine Haken setzen (kein README o. Ä.) → **„Create repository“**.

### 3. Dateien hochladen
1. Auf der Repo-Seite auf **„uploading an existing file“** klicken.
2. Ordner `fahrerradar` öffnen, **alles markieren** und in das Upload-Feld ziehen.
3. **„Commit changes“** klicken.

### 4. Mit Vercel live schalten (ca. 3 Minuten)
1. **vercel.com** → „Sign Up“ → **„Continue with GitHub“**.
2. **„Add New… → Project“** → Repo `fahrerradar` → **„Import“**.
3. Empfohlen: **Settings → Functions → Region → Frankfurt (fra1)** (schnellste Antworten der deutschen Quellen).
4. **Deploy** → 1–2 Minuten warten → deine Adresse: `https://fahrerradar-<deinname>.vercel.app`

### 5. Auf dem Handy wie eine App
1. Adresse am Handy öffnen (Safari bzw. Chrome).
2. **iPhone:** Teilen-Symbol → **„Zum Home-Bildschirm“** → Hinzufügen.
   **Android:** Drei-Punkte-Menü → **„Zum Startbildschirm hinzufügen“**.
3. FahrerRadar liegt mit grünem Radar-Icon auf deinem Startbildschirm und öffnet sich im Vollbild.
